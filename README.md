# map

Codexで作った制作物のURLを一覧管理するシンプルなページです。

## 使い方
1. `index.html` をブラウザで開く
2. タイトルとURLを入力して「追加」
3. 追加したデータはブラウザの `localStorage` に保存されます


## デフォルト登録URL
- ノートアプリ: https://ny-note.vercel.app
- カードゲーム: https://ny-wk-git-codex-add-card-game-transition-button-oqibav-ny1.vercel.app
- スト6: https://ai-colab-six.vercel.app/

初回表示時に上記URLが自動登録され、その後は追加・削除を自由に行えます。
